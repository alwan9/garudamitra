# garudamitra

Website Landing Page Resmi **PT Garuda Mitra Equipment** - Jasa Penyewaan Alat Berat (Excavator PC200, Bulldozer D65, Wheel Loader WA200, Dump Truck 10 Roda, Forklift 3 Ton).

## Fitur Utama
- **Katalog Armada Alat Berat**: Menampilkan spesifikasi teknis, kapasitas, dan tarif sewa harian/bulanan.
- **Kalkulator Estimasi Biaya Sewa**: Simulasi biaya riil dengan opsi operator dan mobilisasi self-loader.
- **Integrasi Langsung WhatsApp**: Routing pemesanan dan konsultasi instan ke nomor WhatsApp operasional.
- **Portofolio Proyek & Testimoni Mitra**: Dokumentasi pengerjaan proyek infrastruktur, jalan tol, dan industri.
- **Desain Modern & Responsif**: Menggunakan tema industri dark zinc dengan tipografi modern dan animasi interaktif.

## Teknologi
- HTML5 Semantic & Responsive Layout
- Vanilla CSS & Tailwind CSS
- Vanilla JavaScript (ES6+)
